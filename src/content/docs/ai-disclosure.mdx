The guides on this website are written, edited, and evaluated for correctness by human contributors. No AI was used in the creation of any text content. This site is built with [Astro Starlight](https://starlight.astro.build/).

Some aspects of this site were generated in part or in full by AI:

**src/components/DutyCount.astro**: An Astro component which counts the total number of guides, updating with every build. This component writes static HTML and does not execute any code on a visitor's browser.

**src/components/DutyPagination.astro**: An Astro component which adds spoiler-free navigation links to Duty pages. This component writes static HTML and does not execute any code on a visitor's browser.

**src/assets/logo.png**: The logo was generated by AI and touched up with Photoshop. This is intended as a placeholder and will be replaced by human art at a later point.
