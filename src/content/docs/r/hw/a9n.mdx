## Refurbisher 0

:::tank

**TB**: Kaltstrahl (Faust Z), Scrap

**OT**: Grab Full Metal Faust asap once it appears, **move it to opposite corner** from where it spawned.
:::

:::healer

**RW**: Panzerschreck (Faust Z), Glowing Squares (if incorrectly solved)

**Scrapline**: If both arms are out, expect a raidwide
:::

---

### Room mechanic

- Squares hold dead robots and/or generator orbs
- Glowing Square: Grab orb, drop it by a robot to tether it, drag the robot into the glowing square, kill it there
- Leave the square when it turns orange

### Main mechanics

- Boss will consume any dead robot still in the arena
  - Gobtanks power up his core - if his core fully powers up, the party wipes
- Marker above head: Move close to boss. Drops rock for next mechanic.
  - **Scrap Burst**: Meteor
- **Scrapline**: 270° Conal, move behind boss
- **Full Metal Faust**
  - Faust needs to be tanked on opposite corner from where it spawned
  - If lava hits Faust, party will most likely wipe!
  - Kill asap. Consider DPS LB.
