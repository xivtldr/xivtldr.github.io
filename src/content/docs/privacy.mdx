This website does not collect, store, or process any personal data itself.
There are no analytics, no tracking scripts, no cookies set by this site, and
no contact forms or accounts.

However, the infrastructure this site runs on processes some data on its own,
outside of our control:

**Hosting — GitHub Pages**
This site is hosted on GitHub Pages. GitHub may log visitor IP addresses and
other technical request data as part of normal server operation.

For more information, read GitHub's Privacy Statement: https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement

**CDN / Security — Cloudflare**
This site is served through Cloudflare, which may process visitor IP
addresses and other technical data for content delivery, caching, and
security/bot protection purposes. Cloudflare may set strictly necessary
cookies for these security functions; these are not used for tracking or
advertising.

For more information, read Cloudflare's Privacy Policy: https://www.cloudflare.com/privacypolicy/

Neither GitHub nor Cloudflare are instructed by us to collect any data beyond
what they process by default to operate their services.

If you have questions about this statement, you can reach us via the contact
options linked on our GitHub repository: https://github.com/xivtldr/xivtldr.github.io.
